## 给 B 的接入说明

- 字段层级与 `TASK-C-VERIFIED-PLACE-IMAGES.md` 一致：`image.url / alt / sourceUrl / license / status`，`status` 均为 `'verified'`。
- 新增字段：`altZh`（中文 alt）、`author`、`credit`、`attributionRequired`、`licenseUrl`、`date`、`originalUrl`。
- `attributionRequired: true` 时，在图片下方用小字显示 `credit`（可链接到 `sourceUrl`）。
- `gallery` 是可选的今昔对照组，第一版可以不显示；以后做“今昔滑动对比”时直接用。
- E6（1918 年火灾现场）带 `contentWarning`，不要作为封面或自动展示。
